## Analysis: Finite Automaton 

### 1. Classification of the Intention Automaton

Within the formal hierarchy of automata, the `Ontology` Intention system operates across three distinct levels of abstraction depending on whether one analyzes the isolated evaluator, the mechanic transducer, or the closed-loop game engine:

```
+-------------------------------------------------------------------------+
| Level 3: Closed-Loop Engine (Cognition <-> Transition <-> Spatial)      |
| -> Reactive Register Automaton / Finite-Control ASM                     |
|                                                                         |
|   +-----------------------------------------------------------------+   |
|   | Level 2: TransitionMechanics                                    |   |
|   | -> Deterministic Moore / Mealy Transducer                       |   |
|   |                                                                 |   |
|   |   +---------------------------------------------------------+   |   |
|   |   | Level 1: CompilerExecutor / LambdaExecutor (main.yaml)  |   |   |
|   |   | -> Priority-Ordered Symbolic Finite Automaton (SFA)     |   |   |
|   |   +---------------------------------------------------------+   |   |
|   +-----------------------------------------------------------------+   |
+-------------------------------------------------------------------------+
```

1. **Level 1 — Evaluator Level (`CompilerExecutor` / `LambdaExecutor`): Priority-Ordered Symbolic Finite Automaton (SFA)**
* **Formal Signature:** $M_{\text{SFA}} = (Q, \mathcal{A}, \Delta, q_0, F)$ where:
* $Q$ is the finite set of $17$ `Intentions` (`attack`, `barter`, `build`, `escape`, `find`, `follow`, `hunt`, `idle`, `interact`, `mine`, `mock`, `return`, `scavenge`, `speak`, `sprint`, `threaten`, `wander`).
* $\mathcal{A}$ is a quantifier-free first-order Boolean algebra of predicates (`environ.py` functions and attribute comparisons) evaluated over the infinite domain $\mathcal{D} = \text{SpriteState} \times \text{Dict}[\text{str}, \text{SpriteState}]$.
* $\Delta$ is a priority-ordered list of guarded transitions for each state $q \in Q$: $T_q = \big[(q_1, \Phi_1), (q_2, \Phi_2), \dots, (q_m, \Phi_m)\big]$.


* **Implicit Determinism & Completeness:** Because `Executor.evaluate()` iterates sequentially through $T_q$ and returns the first `transition.next` whose conjunction $\Phi_i$ evaluates to `True`, and `TransitionMechanics.update()` leaves `sprite.state.intention` unchanged when `evaluate()` returns `None`, the transition function $\delta: Q \times \mathcal{D} \to Q$ is **strictly deterministic and total**:

$$\delta(q, d) = \begin{cases} q_1 & \text{if } d \models \Phi_1 \\ q_i & \text{if } d \models \Phi_i \land \bigwedge_{j=1}^{i-1} \neg \Phi_j \\ q & \text{if } d \models \bigwedge_{j=1}^{m} \neg \Phi_j \quad (\text{implicit stutter / self-loop}) \end{cases}$$




2. **Level 2 — Mechanic Level (`TransitionMechanics`): Moore/Mealy Transducer**
* Following state evaluation, `TransitionMechanics.update()` projects the internal state $(q, d) \in Q \times \mathcal{D}$ into an output alphabet $\Gamma = \text{Actions} \times \text{Directions} \times \mathbb{B}$ via `AnimationMap.action()`, `AnimationMap.direction()`, and `mutators.triggers.animated`.


3. **Level 3 — Closed-Loop Engine (`Cognition` $\to$ `Transition` $\to$ `Navigation` $\to$ `Motion` $\to$ `Spatial`): Reactive Register Automaton / Finite-Control Abstract State Machine (ASM)**
* Because downstream mechanics mutate the domain $d_t \mapsto d_{t+1}$ in response to the current intention $q_t$, and because `SpriteState` stores unbounded entity identifiers and coordinates in registers (`sprite.goal`, `sprite.memory.goals`, `sprite.position`) that are compared across frames (`sprite.layer == sprite.goal.layer`, `sprites.get(sprite.goal.name)`), the coupled system is a **Reactive Register Automaton** (or finite-control Gurevich **Abstract State Machine**).
* **Boundary Implication:** While the open-loop control graph $M_{\text{SFA}}$ is strictly regular over symbolic minterms, the closed-loop reachability of the coupled ASM is undecidable in the general case unless constrained by finite state invariants and well-founded ranking functions.

#### Step 2: Minterm Alphabet ($\Sigma$)

The input alphabet $\Sigma$ is the set of satisfiable truth assignments (minterms) over $\mathcal{P}$, denoted $\Sigma = \{ \sigma \in \{0, 1\}^{17} \mid \sigma \text{ is consistent with } \mathcal{A} \}$ (for instance, $\neg g \implies \neg c_* \land \neg l_{\text{eq}}$ due to the `AttributeError` short-circuit in `CompilerExecutor.evaluate`).

For each ordered transition $(q, \Phi_i, q')$ in `main.yaml`, its effective symbolic label is the disjoint predicate:


$$\Psi_{q \to q'}^{(i)} = \Phi_i \land \bigwedge_{j=1}^{i-1} \neg \Phi_j$$


And every state $q \in Q$ possesses a self-loop $q \xrightarrow{\Psi_{\text{self}}(q)} q$ where:


$$\Psi_{\text{self}}(q) = \bigwedge_{j=1}^{m_q} \neg \Phi_j$$

#### Step 3: Reachable Sub-Automaton & Regular Expression Derivation

As documented in `04-intentions.md`, `idle` is both the start state ($q_0 = \text{idle}$) and the unique accepting state ($F = \{\text{idle}\}$). Inspecting the adjacency matrix of `src/data/config/intentions/main.yaml` reveals that **only 8 of the 17 states are reachable from `idle**`:


$$Q_{\text{reach}} = \{\text{idle}, \text{wander}, \text{find}, \text{interact}, \text{speak}, \text{hunt}, \text{attack}, \text{scavenge}\}$$


The remaining $9$ states (`barter`, `build`, `escape`, `follow`, `mine`, `mock`, `return`, `sprint`, `threaten`) have zero incoming transitions from $Q_{\text{reach}}$.

Letting $\hat{q}$ denote the guarded transition into state $q$ followed by zero or more implicit self-loop ticks $(\Psi_{\text{self}}(q))^*$, we solve the system of language equations for $Q_{\text{reach}}$ via Arden's Lemma ($X = AX \cup B \implies X = A^*B$):

1. **Terminal Leaf Branches (`interact`, `speak`, `scavenge`):**

$$L_{\text{interact}} = \widehat{\text{interact}} \cdot \Psi_{\text{interact}\to\text{idle}}, \qquad L_{\text{speak}} = \widehat{\text{speak}} \cdot \Psi_{\text{speak}\to\text{idle}}, \qquad L_{\text{scavenge}} = \widehat{\text{scavenge}} \cdot \Psi_{\text{scavenge}\to\text{idle}}$$


2. **Find Sub-Loop ($L_{\text{find}}$):**

$$L_{\text{find}} = \widehat{\text{find}} \cdot \Big( \Psi_{\text{find}\to\text{interact}} L_{\text{interact}} \;\mid\; \Psi_{\text{find}\to\text{speak}} L_{\text{speak}} \;\mid\; \Psi_{\text{find}\to\text{idle}} \Big)$$


3. **Combat Sub-Loop ($L_{\text{hunt}}$ and $L_{\text{attack}}$):**
Because `attack` transitions back to `hunt` ($\Psi_{\text{attack}\to\text{hunt}} = \neg g \land m_{\text{tgt}}$) or forward to `scavenge` ($\Psi_{\text{attack}\to\text{scavenge}} = g \land e_{\text{tgt}} \land l_{\text{eq}} \land d_{\text{tgt}}$), substituting $L_{\text{attack}}$ into $L_{\text{hunt}}$ yields:

$$L_{\text{hunt}} = \widehat{\text{hunt}} \cdot \Big( \Psi_{\text{hunt}\to\text{attack}} \cdot \widehat{\text{attack}} \cdot \Psi_{\text{attack}\to\text{hunt}} \cdot \widehat{\text{hunt}} \Big)^* \cdot \Big( \Psi_{\text{hunt}\to\text{idle}} \;\mid\; \Psi_{\text{hunt}\to\text{attack}} \cdot \widehat{\text{attack}} \cdot \Psi_{\text{attack}\to\text{scavenge}} \cdot L_{\text{scavenge}} \Big)$$


4. **Wander Subsumption Sub-Loop ($L_{\text{wander}}$):**

$$L_{\text{wander}} = \widehat{\text{wander}} \cdot \Big( \Psi_{\text{wander}\to\text{idle}} \;\mid\; \Psi_{\text{wander}\to\text{find}} L_{\text{find}} \;\mid\; \Psi_{\text{wander}\to\text{hunt}} L_{\text{hunt}} \Big)$$


5. **Complete Regular Language $\mathcal{L}(M_{\text{reach}})$:**

$$\mathcal{L}(M_{\text{reach}}) = \left( \Psi_{\text{self}}(\text{idle}) \;\mid\; \Psi_{\text{idle}\to\text{wander}} L_{\text{wander}} \;\mid\; \Psi_{\text{idle}\to\text{find}} L_{\text{find}} \;\mid\; \Psi_{\text{idle}\to\text{hunt}} L_{\text{hunt}} \right)^*$$

### 3. General Theorems Applicable to Deduce Properties

Four formal theorems allow you to mechanically prove consistency, liveness, and termination across the Intention Transition Matrix:

#### Theorem 1: Tarjan's Strongly Connected Components (SCC) & Hub Co-Reachability

* **Formal Premise:** Because `04-intentions.md` stipulates that every valid Intention Loop originates at `idle` and terminates at `idle`, the directed graph $G = (Q, E)$ must satisfy two topological invariants for every state $q \in Q$:
1. **Reachability (No Dead States):** $\text{idle} \xrightarrow{*} q$
2. **Co-Reachability (No Topological Cul-de-Sacs):** $q \xrightarrow{*} \text{idle}$


* **Deduction:** Any state $q \in Q$ conforms to the Intention Loop specification if and only if $q$ belongs to the unique Strongly Connected Component containing `idle` ($\text{SCC}(q) = \text{SCC}(\text{idle})$). If $|Q \setminus \text{SCC}(\text{idle})| > 0$, those states are either unreachable orphans or inescapable sink traps.

#### Theorem 2: Priority Minterm Disjointness & Dead-Branch Theorem (Veanes et al., 2012)

* **Formal Premise:** Given an ordered rule list $T_q = [(q_1, \Phi_1), \dots, (q_m, \Phi_m)]$, rule $i$ fires iff $d \models \Phi_i \land \bigwedge_{j=1}^{i-1} \neg \Phi_j$.
* **Deduction (Rule Shadowing):** Transition $i$ is **statically dead (unreachable)** if and only if:

$$\Phi_i \implies \bigvee_{j=1}^{i-1} \Phi_j \quad \Longleftrightarrow \quad \text{UNSAT}\left(\Phi_i \land \bigwedge_{j=1}^{i-1} \neg \Phi_j\right)$$


* **Deduction (Silent Trap Complement):** Whenever the exit conditions of $q$ fail to form a tautology ($\bigvee_{j=1}^{m} \Phi_j \not\equiv \top$), the negation $\Psi_{\text{self}}(q) = \bigwedge_{j=1}^{m} \neg \Phi_j$ defines the exact state subspace in which the Sprite remains trapped in $q$.

#### Theorem 3: Fixed-Point Cul-de-Sac Theorem (Dynamic Deadlock)

* **Formal Premise:** Let $\mathcal{M}_q: \mathcal{D} \to \mathcal{D}$ be the composition of mutations applied by all engine mechanics (`Cognition`, `Navigation`, `Motion`, `Spatial`, `Social`) during a single tick when `sprite.state.intention == q`.
* **Deduction:** A state $q \in Q$ contains a **dynamic cul-de-sac** if there exists a reachable state configuration $d \in \mathcal{D}$ such that:

$$d \models \Psi_{\text{self}}(q) \quad \land \quad \mathcal{M}_q(d) \models \Psi_{\text{self}}(q) \quad \text{for all subsequent ticks } t \to \infty$$



In particular, if $q \in \text{StationaryIntentions}$ ($\vec{v} = \vec{0}$) and no mechanic registered for $q$ mutates `sprite.goal` or `sprite.psyche`, then **any** $d \models \Psi_{\text{self}}(q)$ is an eternal fixed-point freeze ($\mathcal{M}_q(d) = d$).

#### Theorem 4: Discrete Lyapunov / Well-Founded Ranking Theorem (Anti-Thrashing)

* **Formal Premise:** A cycle of transitions $C = (q_1 \to q_2 \to \dots \to q_k \to q_1)$ exhibits **state thrashing (livelock)** if the cycle executes repeatedly without completing a physical or logical task.
* **Deduction:** Cycle $C$ is free of state thrashing if and only if there exists a well-founded ranking function $V: Q \times \mathcal{D} \to \mathbb{N}$ (such as remaining TTL ticks, Euclidean distance to goal, or inventory count) that strictly decreases across each traversal of $C$, or if the entry guard $\Phi_{q_1 \to q_2}$ and exit guard $\Phi_{q_2 \to q_1}$ are separated by a **mechanic mutation barrier** (a state variable mutated exclusively after completion of the multi-tick behavior in $q_2$).

### 5. General Principles of Automaton Design for Completing `main.yaml`

To eliminate cul-de-sacs, dead branches, and state thrashing across all $17$ intentions, apply the following five formal design principles:

#### Principle 1: State Invariant Contracts & First-Rule Preemption

Every intention $q \in Q \setminus \{\text{idle}\}$ exists to service a specific precondition invariant $I(q)$ (e.g., a required `goal.category`, `layer` match, or psyche state).

* **Rule:** Define $I(q)$ explicitly for each state. The **first** transition rule (or final fallback rule) of every non-`idle` state must be an **Invariant Violation Exit** returning to `idle`:

$$\neg I(q) \implies q \to \text{idle}$$


* **Application to `hunt` and `find`:**
* For `hunt`, $I(\text{hunt}) \equiv \text{sprite.goal} \land (\text{goal.category} == \text{TARGET}) \land (\text{sprite.layer} == \text{goal.layer})$. If `CognitionMechanics` subsumes the goal into an `OBJECT` (Door) goal, $\neg I(\text{hunt})$ immediately transitions `hunt -> find` (or `hunt -> idle -> find`), allowing the Sprite to approach and `interact` with the Door.



#### Principle 2: Exhaustive Dichotomy Partitioning ($P$ vs. $\neg P$)

Whenever a transition out of state $q$ splits on a spatial or relational predicate $P$ (such as `is_near`), both branches of the dichotomy ($P$ and $\neg P$) must be explicitly handled:

* **In `idle`:** Either remove `not functions.is_near(...)` from `idle -> find` (letting `find` immediately transition `find -> interact` or `find -> speak` on the next tick, matching how `idle -> hunt -> attack` already works!), OR add direct `idle -> interact` and `idle -> speak` rules when `is_near` is `True`.
* **In `attack`:** Partition by `is_near`:
* If `I(attack)` and `not dead` and `is_near`: `next: attack`
* If `I(attack)` and `not dead` and `not is_near`: `next: hunt` (pursue fleeing target instead of swinging at air).



#### Principle 3: Spatial Hysteresis ($r_{\text{enter}} < r_{\text{exit}}$) to Prevent Boundary Thrashing

When a moving target's distance hovers around `action.radius` ($d \approx r_{\text{act}}$), partitioning strictly on `is_near(..., r_act)` vs. `not is_near(..., r_act)` causes 60 Hz oscillation (`hunt <-> attack` or `speak <-> follow`) as floating-point velocity updates cross the boundary back and forth.

* **Rule:** Introduce a hysteresis band $\epsilon > 0$ (e.g., $\epsilon = 4\text{ px}$ or $1.25 \times r_{\text{act}}$) in `environ.py`:
* **Entry into stationary/action state (`find -> speak`, `hunt -> attack`, `follow -> speak`):** Require $d \le r_{\text{act}}$.
* **Exit back to navigation (`speak -> follow`, `attack -> hunt`):** Require $d > r_{\text{act}} + \epsilon$.



#### Principle 4: Precondition Alignment Between `CognitionMechanics` and `TransitionMechanics`

Never allow an entrypoint transition $\text{idle} \to q$ to fire on a strictly weaker predicate than the downstream interpoint $q \to q'$ unless a Mechanic actively mutates the missing predicate during $q$:

* Since no mechanic mutates `sprite.memory.relationships` during `find`, `idle -> find` (for `SUBJECT`) and `CognitionMechanics._ideate` **must** enforce the same relationship/dialogue precondition as `find -> speak` (or provide an alternative interpoint from `find` for non-allies, such as `find -> barter` or `find -> threaten`).
* In `CognitionMechanics._remember` / `_resolve`, when `any_memories_visible` triggers `wander -> find` or `wander -> hunt` (or inside `CognitionMechanics._scan` when an active `"wander"` position goal is present and a remembered `TARGET`/`SUBJECT` becomes visible), `CognitionMechanics` must preempt and replace the synthetic `"wander"` `POSITION` goal with the visible remembered goal so `find`/`hunt` has the valid `Goal` object immediately.

#### Principle 5: Exception-Safe Predicate Evaluation in `CompilerExecutor` and `LambdaExecutor`

In `src/app/services/translators/compiler.py` and `src/app/services/translators/lamb.py`, broaden `except AttributeError:` to `except (AttributeError, TypeError, KeyError):` so that null dictionary lookups (`prices.get(...)` returning `None` in `<` comparisons) safely short-circuit to `False` rather than crashing the engine loop.

Checks:
1. Tarjan Strongly Connected Components (Reachability from 'idle' & Co-reachability to 'idle').
2. Priority Rule Shadowing (Duplicate or subsumed condition sets).
3. Syntax & AST Compilation validity.
"""
from collections import deque
from pathlib import Path
from typing import Dict, List, Set, Tuple
import yaml


def load_intention_graph(yaml_path: Path) -> Dict[str, List[ dict ]]:
    with yaml_path.open("r", encoding="utf-8") as f:
        data = yaml.safe_load(f)
    return data["intentions"]


def analyze_automaton(intentions: Dict[str, List[dict]]) -> Dict[str, any]:
    states: Set[str] = set(intentions.keys())
    adj: Dict[str, Set[str]] = {s: set() for s in states}
    rev_adj: Dict[str, Set[str]] = {s: set() for s in states}
    shadowed_rules: List[Tuple[str, int, str, int, str]] = []
    syntax_errors: List[Tuple[str, int, str, str]] = []

    for state, rules in intentions.items():
        seen_condition_sets: List[Tuple[int, str, frozenset]] = []
        for idx, rule in enumerate(rules or []):
            target = rule["next"]
            conds = rule.get("conditions") or []
            adj[state].add(target)
            rev_adj.setdefault(target, set()).add(state)

            # 1. Check AST compilation validity
            for c in conds:
                try:
                    compile(c, "<isl>", "eval")
                except SyntaxError as e:
                    syntax_errors.append((state, idx, c, str(e)))

            # 2. Check for Rule Shadowing:
            # If a prior rule's conditions are a subset of (or equal to) the current rule's
            # conditions, the prior rule is logically weaker (more general) and always fires first.
            cond_set = frozenset( " ".join(c.split()) for c in conds )
            for prev_idx, prev_target, prev_set in seen_condition_sets:
                if prev_set.issubset(cond_set):
                    shadowed_rules.append((state, idx, target, prev_idx, prev_target))
            seen_condition_sets.append((idx, target, cond_set))

    # 3. Forward Reachability from 'idle'
    reachable_from_idle: Set[str] = set()
    queue = deque(["idle"])
    while queue:
        curr = queue.popleft()
        if curr not in reachable_from_idle:
            reachable_from_idle.add(curr)
            queue.extend(adj.get(curr, set()) - reachable_from_idle)

    # 4. Backward Co-Reachability to 'idle' (Cul-de-sac detection)
    can_reach_idle: Set[str] = set()
    queue = deque(["idle"])
    while queue:
        curr = queue.popleft()
        if curr not in can_reach_idle:
            can_reach_idle.add(curr)
            queue.extend(rev_adj.get(curr, set()) - can_reach_idle)

    return {
        "all_states": states,
        "unreachable_from_idle": sorted(states - reachable_from_idle),
        "cul_de_sacs_cannot_reach_idle": sorted(states - can_reach_idle),
        "shadowed_rules": shadowed_rules,
        "syntax_errors": syntax_errors,
    }

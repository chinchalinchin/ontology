Composition Configuration

Composition Configuration defines a collection of Assets that can be deployed as a unit onto the Board.

  • Location: /src/data/config/compositions.yaml
compositions:
  <id>:
    root:
      strut:
        id: Strut Asset ID
        name: Strut Name Prefix
      components:
        objects: Object Schema
        crafts: Craft Schema
        effects: Effect Schema
    branches: 
      - strut:
          id: Strut Asset ID
          name: Strut Name Prefix
          owner: Strut Owner
          layer: Strut Layer
          position: Strut Position
        components: 
          objects: Object Schema
          crafts: Craft Schema
          effects: Effect Schema

Mechanics Configuration

Mechanics Configuration defines what Mechanic classes are instantiated by the game engine. The order in which they are specified in the schema becomes the order of execution in the game engine.

  • Location: /src/data/config/mechanics/main.yaml
mechanics:
  order:
    - <mechanic-key>

Default Mechanics Configuration

Recipe Configuration

Recipe Configuration files determine the specific (State, Animation, Frame) components injected into an Asset Category Instance. The Category and Instance key are encoded into the top-level fields of each Recipe.

  • Location: /src/data/config/recipes/main.yaml
assets:
  # <asset-category>: tiles, cursors, effects, objects, sheets, widgets
  <asset-category>:
    # <asset-instance>: fore, back,
    #                   expressions, projectiles, 
    #                   temporary, persistent, 
    #                   chests, crates, doors, gates, plates, struts
    #                   pixies, sprites
    #                   buttons, choices, containers, language, meters, windows
    <asset-instance>: 
        # <frame-implementation: single, iterable, state
      frame: <frame-implementation> 
        # <animation-implementation>: temporary, persistent, binary, state
      animation: <animation-implementation> 
        # <state-implementation> sprite, switch, door, positional, 
        # property, container, animator, metric
        # multiplier
      state: <state-implementation>

        - <condition-for-transition>

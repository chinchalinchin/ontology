# Minor Damage

This is a sheet of 2D pixel art walls, each 96px by 96px. The cells of the sheet represent different materials: sandstone, stone, slate and marble. Edit each cell so they look like they have sustained minor damage and are beginning to show wear. Assume the same destructive force is applied to each material, so the resilience of the material can be determined by visible inspection, i.e. damage should be more severe for sandstone and less severe for marble.

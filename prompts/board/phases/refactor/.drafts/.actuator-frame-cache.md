### 1. Architectural Problem Analysis

#### The Root Cause

1. **Cross-Layer Coupling (SRP Violation)**: `Actuator` is a procedural physics/generation service responsible for raycasting, obstacle truncation, pool expansion, and branch bifurcation. Directly clearing `fluid.state._keys` forces a simulation worker to manage graphics-pipeline cache structures.
2. **Temporal Race Condition (Bug B014)**: The engine executes in two distinct phases:

$$\text{Engine.start()} \implies \text{Engine.\_play() (Mechanics \& Actuators)} \longrightarrow \text{Engine.\_render() (Screen \& Frames)}$$

A binary flag (`state.dirty: bool`) fails when reset eagerly during `_play()`, because `FluidFrame.keys()` in `_render()` never observes the dirty transition.
3. **State Model Pollution**: Storing `_keys: Dict[int, List[Tuple[...]]]` directly on `FluidState` mixes transient VRAM crop keys with serializable domain state.

---

### 2. Formal Assumptions

* **Assumption A1 (Domain Invariance)**: `FluidState` models physical world data (`length`, `pool`, `branches`, `hitboxes`). It must remain serializable and decoupled from graphics rendering.
* **Assumption A2 (Render Lifecycle)**: `FluidFrame.keys()` is evaluated during `_render()`, which may run after zero, one, or multiple `_play()` logic steps (fixed-timestep accumulator).
* **Assumption A3 (Cache Ownership)**: Rendering caches belong to the presentation layer (`FluidFrame` or `Screen`), indexed by geometry state.

---

### 3. Proposed Solutions

#### Proposal 1: Monotonic Revision Counter (Epoch Tracking) — *Recommended*

Replace the boolean `dirty` flag and direct cache clears with a monotonic revision counter on the state model. The cache checks the revision on evaluation, decoupling eviction from generation.

##### Mechanics

1. Add `revision: int = 0` to `FluidState`.
2. When `Actuator.propagate()` alters geometry, increment `state.revision += 1`.
3. In `FluidFrame`, store `_cache: Dict[int, List[Tuple[str, int, int]]]` and `_cached_revision: int = -1`.
4. On `FluidFrame.keys()`, evict when `state.revision != self._cached_revision`.

```python
# src/app/models/state/assets/effects.py
@dataclass(slots=True)
class FluidState(EffectState):
    length: int = 0
    pool: Optional[Pool] = None
    branches: List[Branch] = field(default_factory=list)
    hitboxes: List[Hitbox] = field(default_factory=list)
    revision: int = 0  # Monotonic geometry version

```

```python
# src/app/services/generators/game/actuator.py
def propagate(self, fluid: Asset, board: Board) -> Tuple[...]:
    # ... compute stream_length, pool_bounds, branches, hitboxes ...
    
    # Check if geometry actually shifted before bumping revision
    if (
        fluid.state.length != stream_length or
        fluid.state.pool != pool_bounds or
        len(fluid.state.branches) != len(branches)
    ):
        fluid.state.revision += 1

    fluid.state.length = stream_length
    fluid.state.pool = pool_bounds
    fluid.state.branches = branches
    fluid.state.hitboxes = hitboxes
    # NO reference to _keys or dirty flags here
    return stream_length, pool_bounds, hitboxes

```

```python
# src/app/assets/frames/effects.py
class FluidFrame(Frame):
    def __init__(self, tile_w: int = 32, tile_l: int = 32):
        self.tile_w = tile_w
        self.tile_l = tile_l
        self._cache: Dict[str, Dict[int, List[Tuple[str, int, int]]]] = {}
        self._cached_revisions: Dict[str, int] = {}

    def keys(self, id: str, state: FluidState) -> List[Tuple[str, int, int]]:
        entity_key = state.name or id
        current_rev = state.revision
        cached_rev = self._cached_revisions.get(entity_key, -1)

        if current_rev != cached_rev:
            self._cache[entity_key] = {}
            self._cached_revisions[entity_key] = current_rev

        frame_idx = state.animation.frame
        entity_cache = self._cache[entity_key]

        if frame_idx in entity_cache:
            return entity_cache[frame_idx]

        frame_keys = self._decompose(id, state, frame_idx)
        entity_cache[frame_idx] = frame_keys
        return frame_keys

```

* **Pros**: Eliminates temporal ordering dependencies between `_play()` and `_render()`; eliminates cache references in `Actuator`; preserves $O(1)$ amortized lookups.
* **Cons**: Requires tracking per-entity cache dictionaries if `FluidFrame` is shared across multiple fluid assets.

#### Proposal 2: Content-Addressed Geometry Hash (Value-Based Cache)

Cache keys using a composite key: `(geometry_signature, animation_frame)`.

##### Mechanics

1. Define a lightweight geometry signature on `FluidState`:

$$\text{sig} = (state.length, (p.x, p.y, p.w, p.l) \text{ if } pool \text{ else None}, \text{tuple}(b.position.x, b.position.y, b.length \text{ for } b \in branches))$$


2. `FluidFrame` caches by `(sig, frame_idx)`.
3. Use a bounded 2-slot or LRU cache per entity.

```python
# src/app/assets/frames/effects.py
class FluidFrame(Frame):
    def __init__(self, tile_w: int = 32, tile_l: int = 32):
        self.tile_w = tile_w
        self.tile_l = tile_l
        self._cache: Dict[Tuple[int, int, Tuple], List[Tuple[str, int, int]]] = {}

    def _signature(self, state: FluidState) -> Tuple:
        pool_key = (state.pool.x, state.pool.y, state.pool.w, state.pool.l) if state.pool else None
        branch_key = tuple((b.position.x, b.position.y, b.length) for b in state.branches)
        return (state.length, pool_key, branch_key)

    def keys(self, id: str, state: FluidState) -> List[Tuple[str, int, int]]:
        frame_idx = state.animation.frame
        cache_key = (frame_idx, self._signature(state))

        if cache_key in self._cache:
            return self._cache[cache_key]

        frame_keys = self._decompose(id, state, frame_idx)
        # Prevent unbounded growth: clear if geometry drifts
        if len(self._cache) > 16:
            self._cache.clear()
        self._cache[cache_key] = frame_keys
        return frame_keys

```

* **Pros**: Zero explicit invalidation or clearing calls anywhere in the codebase; oscillating gate transitions (open $\leftrightarrow$ close) hit existing cache slots instantly without recomputation.
* **Cons**: Minor tuple allocation on every frame key check to construct the signature tuple during `Screen.draw()`.

#### Proposal 3: Transition Boundary Invalidation in `FluidMechanics`

Relocate invalidation to `FluidMechanics.update()`, which already computes `pre_sig` and `post_sig` across layer fluids.

##### Mechanics

1. `Actuator.propagate()` remains purely functional: takes `(fluid, board)` and returns updated geometric primitives without touching `_keys` or `dirty`.
2. `FluidMechanics.update()` checks `pre_sig != post_sig`.
3. If shifted, `FluidMechanics` invalidates:
```python
if pre_sig != post_sig:
    for f in layer_fluids:
        f.frame.invalidate(f.name)  # or f.state._keys.clear()

```



* **Pros**: Keeps invalidation logic aligned with `Cartographer.purge()` / `Cartographer.generate()`.
* **Cons**: Leaves cache eviction push-based; if a fluid's geometry is updated outside `FluidMechanics` (e.g., world hydration, map transitions, or tests), the cache goes stale.

### 4. Comparison & Synthesis

| Criterion | Proposal 1: Monotonic Revision | Proposal 2: Value-Based Hash | Proposal 3: Mechanics Hook |
| --- | --- | --- | --- |
| **Separation of Concerns** | **High**: Actuator bumps int; Frame owns cache | **High**: Zero cache awareness in physics | **Medium**: Mechanics coordinates graphics cache |
| **Inner-Loop Allocation** | **Zero**: Integer comparison (`rev != cached_rev`) | **Low**: Allocates signature tuple per check | **Zero**: Direct dictionary clear |
| **Immunity to Timing Bugs (B014)** | **Total**: Independent of `_play`/`_render` order | **Total**: Purely declarative | **Partial**: Requires correct tick sequencing |
| **State Cleanliness** | Moves `_keys` off `FluidState` to `FluidFrame` | Moves `_keys` off `FluidState` to `FluidFrame` | Leaves `_keys` on `FluidState` |

### Recommended Action Plan

1. **Adopt Proposal 1**: Add `revision: int = 0` to `FluidState` and remove `_keys` from `FluidState`.
2. **Move Cache Storage into `FluidFrame**`: Let `FluidFrame` hold its own `_cache` and `_cached_revisions` indexed by entity name/ID.
3. **Strip Frame Concerns from `Actuator**`: In `Actuator.propagate()`, remove `fluid.state._keys.clear()` and `fluid.state.dirty = False`. Increment `fluid.state.revision += 1` only when output dimensions change.
